# OndineMrCai.github.io

Source code for my personal academic homepage, served via GitHub Pages at [https://OndineMrCai.github.io](https://OndineMrCai.github.io).

## Local preview

Run from the repository directory, then open http://127.0.0.1:4000/ to preview the site:

```bash
bundle exec jekyll serve --host 127.0.0.1 --port 4000
```
